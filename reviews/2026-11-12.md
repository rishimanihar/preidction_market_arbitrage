## Findings

| ID | Priority | Evidence and requested change |
|---|---|---|
| R1 | High | The actual collector emits `adapter_error`, while the report counts `error`. One recorded synthetic adapter outage reports zero errors. Align the event contract and add a producer-to-report regression. |
| R2 | High | Actual queue backpressure emits `recording_backpressure`, which report gap classification misses. The independent test reports zero backpressure gaps instead of one. Normalize event kinds, including restart events. |
| R3 | High | Health events contain combined `last_book_age_s` data; the report expects venue-specific `fresh` state. Valid fresh books do not produce per-venue freshness coverage. Persist defined freshness/validity state and use it consistently. |
| R4 | Medium | Packaged migrations create schema v2, but `pmarb doctor` requires v1. A current migrated DB is rejected. Derive the supported version from storage. |
| R5 | High on Windows | Review filenames contain timestamp colons. Writing an ordinary decision fails with WinError 123. Use filesystem-safe filenames and share the spool-writing implementation. |
| R6 | High on Windows | `os.open(directory, os.O_RDONLY)` raises PermissionError during directory-fsync operations in DB creation, raw logging and review intake. Implement Windows durability handling or explicitly choose a supported deployment platform. |
| R7 | Needs diagnosis | Collector shutdown test stalls locally. Diagnose the saved traceback and add a bounded shutdown regression; no Linux failure is established by this run. |
| R8 | High for Windows M2 | POSIX chmod-based key tests still see modes such as 0666 on Windows and stop before key-format/signing assertions. Add an ACL-aware policy or use a supported POSIX runtime; retain credential protections. |

R1–R6 were reproduced with the independent acceptance checks under
`reviews/checks/test_review_regressions.py`. A positive control confirms that an
actual collector event with typed `status_code=429` reports one rate-limit event.
This does not prove that every internally retried HTTP 429 is instrumented.
